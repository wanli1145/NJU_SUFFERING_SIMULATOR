# 南大受苦模拟器 (NJU Suffering Simulator)

一款类杀戮尖塔（Slay the Spire）风格的卡牌肉鸽游戏，主题是南京大学学生的 12 周受苦旅程。

## 玩法

- 你扮演一名南大学生，需要在 12 周内活下来
- 用卡牌战斗，对抗 DDL、点名老师、2.4km 体测，最终迎战期末周 BOSS
- 通过事件做出选择，影响心态、生活费、GPA
- 触发不同的结局（S/A/B/C/F）

## 核心系统

- **心态 (HP)**：归零即心态崩了
- **GPA**：通过累积学分换算，影响最终评价
- **生活费**：用于购买和事件消耗
- **精力**：每回合刷新，用于打牌
- **效率（防御）**：抵扣伤害

## 卡牌流派

- 📚 **学业牌** — 高伤害、积学分
- 🎮 **娱乐牌** — 回血、防御、组合技
- 🤝 **社交牌** — 抽牌、白嫖、特殊机制
- 💀 **诅咒牌** — 各种负面 buff

## 怎么玩

直接打开 `index.html` 即可。或访问在线版本（如果部署了 GitHub Pages）。

## 技术栈

- 纯 HTML / CSS / JavaScript，无依赖
- 浏览器 localStorage 存档
